# Guide to Office Document Question Answering

## Overview
This guide helps you answer questions about office documents, financial
reports, and statistical publications. Questions typically ask for specific
values, calculations, or comparisons drawn from official tables.

## Approach

1. **Understand the question.** Identify what is asked — a value, a
   calculation, a comparison, or a ranking — and the relevant period or
   entity.
2. **Locate the evidence.** Search for the relevant table or document using
   precise terms that name the entity, measure, and time period.
3. **Extract carefully.** Read the table structure: row labels, column
   headers, and units. Make sure you understand what each value represents.
4. **Compute if needed.** Perform the requested arithmetic, keeping units
   consistent.
5. **Format the answer.** Follow any specified format exactly.

## Best Practices

- Read table headers carefully to understand units (thousands, millions,
  percent, ratios) before using any value.
- Double-check that the numbers you use come from the correct row and column.
- Keep calculations simple and verify them once before answering.
- When comparing values across periods, make sure the basis is consistent.
- Present the final answer clearly and concisely.

## Common Mistakes

- Mixing units (e.g., thousands vs millions) in a single calculation.
- Reading a value from the wrong row or year.
- Rounding too early, which introduces errors in multi-step calculations.
- Adding unnecessary words to the final answer.

Follow these guidelines and answer precisely.

## Working with Official Publications

- Official releases often present data in fixed tables with clear row and
  column labels. Match the question's terms to the table's labels before
  extracting values.
- Some tables report figures in thousands or millions; the header or
  footnote states the unit. Read it before using any number.
- When a question asks about a specific month or year, make sure the value
  you extract corresponds to exactly that period.
- If multiple tables report similar measures, choose the one whose title
  matches the question's wording most closely.

## Verification

- Re-read the question after computing your answer to confirm you answered
  what was asked.
- Check that the magnitude of your answer is reasonable.
- Confirm the final formatting matches the question's requirements.

## Understanding Question Types

- **Direct lookup**: find the stated value in the stated table.
- **Calculation**: combine two or more values (difference, ratio, sum,
  growth rate).
- **Comparison**: retrieve values for each item and order or select them.
- **Counting**: enumerate periods or items meeting a condition.

Identify the type first; each has a different verification step at the end.

## Final Reminder

Stay grounded in the retrieved evidence, compute only from verified values,
and answer in exactly the requested format.

## Note on Precision

- Keep full precision through every intermediate step.
- Round only at the end, to the precision the question requests.
- When a question asks for rounding (nearest tenth, nearest thousand),
  apply it exactly once to the final value.

## One Last Check

- Does the answer use the exact unit requested?
- Is the rounding applied once, at the end?
- Is the format (commas, decimals, symbols) exactly as specified?
