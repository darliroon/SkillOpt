SkillOptMicrosoft Research
arXiv 2605.23904 · 2026
梯度下降同构 — 技能文档即「权重」
把 Markdown 技能当可训练参数,完整照搬 DL 训练纪律:epoch / minibatch / 学习率 / 调度器 / 动量 / 验证门控,产出一份可部署的 best_skill.md。
Rollout → Reflect → Aggregate
→ Select(LR 裁剪) → Update → Gate
Epoch 边界:慢更新(动量) + 元技能
关键技术点
▪文本梯度:轨迹反思产出 add/del/replace 有界编辑补丁
▪学习率裁剪:每步最多改 L 条 → 防过冲震荡
▪留出集严格门控:打平即拒、坏编辑回滚,泛化有保障
▪缓冲区复用:被拒编辑下轮再用;慢更新防跨轮遗忘
▪元技能:累积"哪些编辑有效/有害"的优化器记忆
▪可迁移:跨模型 / 跨 Harness / 跨相邻任务直接复用
一句话成果6 benchmark × 7 模型 × 3 harness 共 52 格全部 best/tied-best,GPT-5.5 直聊 +23.5 分、Codex +24.8、Claude Code +19.1,产物仅 300–2000 token、零额外推理调用。
GEPAUC Berkeley / Stanford
ICLR 2026 Oral
反思式进化 — Pareto 前沿种群搜索
不维护单一最优,而是维护候选种群;评测函数除分数外还回传自然语言反馈(报错、编译输出、约束违规)供反思变异。
Pareto 前沿选亲代 → minibatch 带轨迹评测
→ 自然语言反思变异 → 前沿更新
→ 跨候选合并互补经验(交叉)
关键技术点
▪Pareto 前沿选择:在任一样本上最强即存活 → 防早熟收敛、保种群多样性
▪NL 反馈反思变异:利用富文本反馈而非仅标量分数,信息量远超 RL 奖励
▪经验继承:变异继承祖先经验,少量 rollout 也有大增益
▪跨候选交叉:合并不同候选的互补优势
▪推理期搜索:可直接用于代码优化、ARC 推理等场景
一句话成果较 GRPO 平均 +10%(最高 +20%)而 rollout 少至 1/35;较 MIPROv2 高 10%+ 且 prompt 短至 1/9.2 —— 用极少样本打败强化学习。
DSPy / SIMBAStanford NLP
dspy.SIMBA · 2025–2026
声明式编程 + 老虎机难例自反思
DSPy 把 LLM 管线写成声明式模块(Signature+Module),优化器自动编译 prompt。SIMBA 是其代表优化器:按输出方差分桶,专攻模型"时对时错"的难例。
Minibatch 采样 → 多温度跑轨迹
→ 按方差分桶:高方差=难例优先
→ append_a_rule(对比好坏轨迹→规则)
或 append_a_demo(加成功示例)
关键技术点
▪声明式抽象:prompt 与逻辑解耦,换模型/换优化器零改代码
▪多臂老虎机选择:softmax 采样候选,平衡利用/探索
▪方差驱动难例聚焦:注意力不均匀分配给硬样本
▪双策略产出:规则(泛化)或 demo(具体),按需选择
▪生态最全:GEPA 已并入 DSPy 优化器家族,工程落地首选
一句话成果比 MIPROv2 更样本高效、更稳定,是 GEPA 的直接前身;DSPy 框架已成 prompt 工程事实标准,声明式管线 + 自动优化开箱即用。
