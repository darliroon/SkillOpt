② 六阶段自演进闭环 — 每一步做什么、输入输出、DL 类比

▶
Rollout
目标模型用当前技能文档作为 prompt 执行任务,产出执行轨迹 + 分数(类比 minibatch 前向传播)
技能+任务 → 轨迹+分数
⟲
Reflect
优化器模型分析 minibatch(8条)轨迹,识别共性失败/成功模式,产出结构化编辑补丁(add/del/replace)
轨迹+技能 → 编辑补丁
⇄
Aggregate
语义相似补丁层级化合并去冗余;失败补丁优先于成功补丁(纠正 > 强化)
多组补丁 → 一条合并补丁
✂
Select
按系统性影响/互补性/通用性排序,学习率 LR 限制每步最多应用 L 条编辑(类比梯度裁剪)
合并补丁 → Top-L 编辑
✎
Update
选中编辑按 op(append/insert_after/replace/delete)应用到技能文档,产出新版本(类比 optimizer.step())
旧技能+编辑 → 新技能
✓
Gate
新技能在留出验证集上评估,只有严格优于当前才接受;否则回滚,补丁进 step_buffer 下轮复用
新技能 → 接受/拒绝
Epoch 边界(跨轮次): 🌀 慢更新 Slow Update(=动量)— 纵向对比两版技能在同一批任务上的表现,防跨 Epoch 灾难性遗忘,写入受保护区块  |  🧠 元技能 Meta Skill(=元学习)— 累积"哪些编辑倾向有效/有害"的优化器策略记忆,指导下轮 Reflect

# Question Answering Skill
## Common Clue Traps
- 注意逆向关系:"His third wife was Jiang Qing"→答丈夫
- "include/like/such as"列实体→应答父类
## Concise Answer Normalization
- 自然地理特征保留 Lake/River/Bay/Mount 词
- 公司名省略 Company/Inc.,保留 surface form
## Clue Interpretation
- Jeopardy 式措辞推断答案类型,修饰语当硬过滤
↳ 6 章节、数千字结构化策略
↳ 全部由优化器从轨迹归纳+门控验证后写入
关键:一步循环 = Rollout→Reflect→聚合→选择→Update→Gate;多轮循环后空白种子长成 6 章节策略。Epoch 间用慢更新防遗忘、元技能累积优化器记忆。整个过程不碰模型权重,只改这一份 Markdown。
一句话:把 Markdown 当权重,用文本梯度(编辑补丁)在留出集门控下迭代更新;Epoch 间用慢更新防遗忘、元技能累积优化器记忆 → 产出一个紧凑、可跨模型迁移、零额外调用的 best_skill.md
