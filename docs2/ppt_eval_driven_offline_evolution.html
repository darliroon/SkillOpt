以 Eval 标注驱动的大批量离线学习自演进

技术路线全景 强监督信号 · 可复现训练 · 留出集守门 · 产物是一段可读文本
A整体目标:少批量交互演进 做不到 的六件事,只有大批量 Eval 离线学习能做到论证方式:不谈通用痛点,只谈能力边界差异
关键能力
✗ 少批量交互数据演进的边界
✓ 大批量 Eval 标注演进的解法
① 正确性判定
✗无 ground truth,只能靠 LLM-as-judge 或用户是否追问来猜对错,judge 噪声与真实错误无法分离
✓标注即裁判:精确匹配 / 单元格比对 / 代码执行,信号无歧义,优化方向唯一
② 提升可证伪
✗样本量在个位数到几十,±1–2 pt 的run-to-run 噪声就能淹没真实效果,「变好了」无法证伪
✓train/val/test 三切分 + 千级样本(SearchQA 1400 / SpreadsheetBench 280),提升统计显著
③ 覆盖完备性
✗只见到用户实际问过的任务,分布高度偏斜;没触发过的失败模式永远学不到
✓benchmark 系统性铺满任务空间,主动暴露未被触发的短板,建立能力基线
④ 防过拟合
✗少量样本 + 弱信号,极易把个人偏好或偶发错误固化进技能,污染通用能力
✓留出集严格单调门控:打平即拒、坏编辑回滚,泛化性由未见过的数据裁决
⑤ 可复现 / 可调参
✗数据随用户行为漂移,无法重跑,超参搜索、消融实验、方案 A/B 都做不了
✓数据集固定 + 随机种子固定 → 可网格搜 LR × 调度器,可做消融与横向对比
⑥ 冷启动能力
✗依赖已有交互历史,新场景 / 新用户零样本时无从演进,天生只能做增量微调
✓可从空白技能从零训出可交付资产,并跨模型 / 跨 Harness / 跨相邻任务迁移复用
结论:少批量交互演进负责「长尾个性化」——它无法建立、也无法证明能力基线;大批量 Eval 离线学习是唯一能产出可验证、可复现、可迁移基线技能的路径。二者是 预训练 → 微调,不是二选一。
B三条特色技术路线 — 同一目标下的三种「优化器」思路差异核心:如何把 Eval 分数变成对文本的改动
SkillOptMicrosoft · arXiv 2605.23904
思路一:深度学习同构 — 技能即权重
把 Markdown 技能文档当作可训练参数,完整照搬 DL 训练纪律:epoch / minibatch / 学习率 / 调度器 / 动量 / 验证门控。
Rollout → Reflect → Aggregate
→ Select(LR 裁剪) → Update → Gate
Epoch 边界:慢更新(动量) + 元技能
▪轨迹反思产出 add/del/replace 有界编辑,等价于「文本梯度」
▪学习率限制每步最多改几条 → 防止过冲震荡
▪被拒编辑进缓冲区下轮复用,慢更新对抗跨轮遗忘
成绩:6 benchmark × 7 模型 × 3 harness = 52 格全部 best/tied-best;GPT-5.5 直聊 +23.5 分、Codex +24.8、Claude Code +19.1。产物仅 300–2000 token。

思路二:反思式进化 — Pareto 前沿种群搜索
不维护单一最优,而是维护一个候选种群;评测函数除分数外还回传自然语言反馈(报错、编译输出、约束违规)供反思。
Pareto 前沿选亲代 → minibatch 带轨迹评测
→ 自然语言反思变异 → 前沿更新
→ 跨候选合并互补经验(交叉)
▪Pareto 选择:在任一样本上最强即存活 → 防早熟收敛
▪变异继承祖先经验,少量 rollout 也有大增益
▪可作推理期搜索用于代码优化、ARC 推理
成绩:较 GRPO 平均 +10%(最高 +20%)而 rollout 少至 1/35;较 MIPROv2 高 10%+ 且 prompt 短至 1/9.2。
SIMBA / DSPyStanford NLP · dspy.SIMBA · 2025–2026
思路三:随机内省小批量上升 — 瞄准高方差难例的自反思
GEPA 的前身。采样小批量后按输出方差给样本分桶排序,专攻模型"时对时错"的难例;让 LLM 对比好坏轨迹自反思,产出具体改进规则或添加成功 demo。
Minibatch 采样 → 多温度跑轨迹
→ 按方差分桶:高方差=难例优先
→ append_a_rule:对比好坏轨迹→规则
或 append_a_demo:加成功示例
▪多臂老虎机选择:softmax 采样候选,平衡利用/探索
▪方差驱动的难例聚焦:不均匀分配注意力给硬样本
▪双策略:规则(泛化)或 demo(具体),按需选择
特点:比 MIPROv2 更样本高效、更稳定;需较强 LLM(3B 以下可能不如简单优化器)。是 GEPA 的直接前身,GEPA 在其基础上加了 Pareto 前沿 + NL 反馈。
